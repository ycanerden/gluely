# Find an excuse

An excuse is the honest reason to reach out now. Read `principle-excuse-first`.

1. Gather what's known about the person, and mark how fresh it is.
2. Run `gluely check company <domain> --json`. Stop if it's blocked.
3. Read `context/messaging/excuses.md` and the matching persona.
4. List up to three possible excuses, strongest first. For each one, ask: is it true, is it recent, and would they care?
5. Draft one message for the best excuse.
6. Run `gluely check draft --channel <channel> --text "<draft>" --json` and fix any violation.
7. Show the excuse, the source and the draft. A human decides.

If no excuse survives, say "no message" and explain why. That is a good outcome.
