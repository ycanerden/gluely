# Review a pilot

Find out why drafts fail before anyone sends at scale.

1. Run every draft through `gluely check draft --json`.
2. Show drafts one at a time: person, excuse, draft. Ask the founder to approve, edit or reject, with a reason.
3. Group the rejections: wrong person, wrong company, weak excuse, wrong tone.
4. Propose the smallest context fix for each group, in `icp.md`, a persona or `voice.md`.
5. Turn each repeated rejection into a test with `gluely test add`.
6. Aim for 70% approved unchanged before suggesting more volume.
