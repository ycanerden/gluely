# Your stack

Gluely is the glue, so you keep your tools. Name them with `gluely stack set <layer> <tool>`. Any name works, including "a spreadsheet".

These are examples to help you choose. None is required, and Gluely gives none of them special treatment.

| Layer | Examples | How to think about it |
|---|---|---|
| Agent | Claude Code, Cursor, Codex, Grok | Whatever you already reason with |
| Data store | SQLite, Postgres, Supabase, Snowflake, BigQuery | Solo work suits a local file. Teams and schedules need something shared. Use your warehouse if your data already lives there |
| CRM | HubSpot, Attio, Salesforce, Pipedrive | Keep the one you have |
| Outreach | Instantly, Smartlead, Lemlist, HeyReach, Gmail drafts | Gluely never sends, so anything works, including by hand |
| Signals | Apify, PhantomBuster, Clay, Unipile, manual exports | Check each source's terms and your legal basis |
| Enrichment | Clay, Icypeas, Prospeo, People Data Labs | Enrich only people a play needs |
| Transcripts | Fathom, Granola, Fireflies, Gong | Always with consent |
| Product data | PostHog, Amplitude, your warehouse | For product-led motions |
